One funny line for make.fun's "The One-Line Laugh" bounty: a single sentence of at most 200 characters, written by `main.ts` to `/output/entry.txt`. The line plays on an everyday truth everyone recognises — buying noise-cancelling headphones to escape the neighbours — and lands its surprise at the very end: the thoughts left behind are worse than the neighbours were.

> I bought noise-cancelling headphones to escape my neighbours, and now all I hear is my own thoughts — turns out they're worse.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` — the whole entry, one line, 126 characters.
